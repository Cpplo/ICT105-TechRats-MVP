# Final Venture Pitch Outline
Recommended length: 7-10 minutes

## Slide 1: Project Title and Team
**Student Internship & Entry-Level Job Platform**

Team Tech Rats:
- Hein Pyae Shan - Product Lead
- Phyo Wai Aung - Technical Lead
- Kyaw Phone Thant - UX/UI Lead & Documentation Lead

Opening point:
- We are building a platform that helps students find verified internships and entry-level jobs, while helping employers recruit beginner talent through a trust-based workflow.

---

## Slide 2: Problem and Target Users
### Problem
- Students and fresh graduates struggle to find trustworthy beginner-friendly jobs.
- Many “entry-level” jobs still require experience.
- Employers need a simple way to reach and screen beginner candidates.
- Trust is a major issue because fake or unclear job posts reduce confidence.

### Target Users
- University students
- Fresh graduates
- SMEs
- Startups
- Employers
- Admin users for verification and report handling

---

## Slide 3: Evidence from Customer Discovery and Validation
### Customer Discovery Evidence
- Students said they want a dedicated place for internships and entry-level jobs.
- Employers said they want better applicant information and trust signals.
- Both groups highlighted verification as important.

### Validation Evidence
- Users understood the browsing, detail, and application workflows.
- Beginner-friendly labels improved clarity.
- Company verification badges increased trust.
- Application tracking was useful, but should be easier to find.
- Admin verification and report handling still need clearer labels.

### Key Insight
- Trust, verification, and beginner-friendly filtering are the strongest value drivers.

---

## Slide 4: Solution and Value Proposition
### Solution
A web-based platform where:
- Students browse and apply for verified beginner-friendly jobs
- Employers post jobs only after verification
- Admin reviews verification requests and reported jobs

### Value Proposition
- For students:
  - verified employers
  - clear eligibility
  - saved jobs
  - application tracking
- For employers:
  - verified student talent
  - applicant review tools
  - easier recruitment workflow
- For the platform:
  - trust-based differentiation
  - role-based workflows
  - clear MVP direction

---

## Slide 5: Final Prototype Demonstration Flow
### Demo Flow
1. Open landing page
2. Show project introduction and key features
3. Open login / role selection
4. Enter Student Dashboard
5. Browse and filter jobs
6. Open Job Detail Page
7. Check company verification badge and eligibility
8. Apply for a job
9. Track application status
10. Switch to Employer Dashboard
11. Review applicants
12. Update application status
13. Show Admin Verification / Report Handling page
14. End with closing summary

### Demo Point
- The prototype is interactive and demonstrates the full student-employer-admin workflow.

## Slide 7: Product/Startup Metrics and User Testing Findings
### Product Metrics
- Landing page visits
- CTA clicks
- Total job applications
- Pending applications
- Task completion rate
- Ease-of-use score

### User Testing Findings
- Users could complete the main job browsing and application flow.
- Verification badges improved trust.
- Beginner-friendly filters were helpful.

- Admin report handling and verification labels need improvement.

## Slide 8: Technical Architecture and Data Handling
### Technical Architecture
- HTML5
- CSS3
- JavaScript
- Simulated frontend-only prototype
- No production database
- No real authentication system

### Data Handling
- Sample data stored in JavaScript arrays
- Local simulation for:
  - students
  - employers
  - jobs
  - applications
  - conversations
  - reviews
  - saved jobs
  - reports
  - verification requests
  - notifications
  - activity logs
- Landing page acquisition metrics stored locally using `localStorage`

### Why this matters
- The prototype demonstrates realistic workflows without requiring a production backend.
