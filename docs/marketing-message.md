# Marketing Message

## Short One-Sentence Message
We're testing a platform where students find verified, beginner-friendly internships and employers recruit verified early-career talent.

## Channel-Specific Messages

| Channel | Message | CTA | Link/QR Placeholder |
| --- | --- | --- | --- |
| Class/course chat group | Tired of guessing which internship posts are real? Try our verified internship demo. | Try Demo | [Insert link] |
| Campus poster/QR | Find verified, beginner-friendly internships. Scan to try the demo. | Scan QR | [Insert QR/link] |
| University career center / student club (email or Instagram) | We're piloting a platform to help students find verified internships and entry-level jobs — take a look. | Try Demo | [Insert link] |
| LinkedIn (employers) | Recruiting beginner talent? Try our platform for posting verified internship and entry-level roles. | Give Feedback | [Insert link] |

## Message Quality Check
- Is the message clear within 5 seconds? Yes — each message states the user type and the core value (verified jobs/talent) in one line.
- Does it identify the target user? Yes — students for the first three channels, employers for the LinkedIn message.
- Does it explain the problem or benefit? Yes — the difficulty of telling legitimate listings apart (students) and reaching verified beginner talent (employers).
- Does it include one action? Yes — each row has exactly one CTA (Try Demo, Scan QR, or Give Feedback).
- Does it avoid exaggerated claims? Yes — messages describe the prototype as being tested/piloted rather than promising guaranteed job placement or hiring outcomes.
